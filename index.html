Machine Learning · Chrome Extension

Redirection Guard — Phishing Blocker

A lightweight, AI-powered Chrome extension that detects and blocks redirect-based phishing during the redirect phase — before the warning comes too late. A two-tier engine checks a blacklist first, then a fine-tuned Gemini model. Research supervised by Dr. Doowon Kim, using PhishTank, Tranco, and VirusTotal.

100ms latency 15,666 URL dataset 90% accuracy
TypeScript Gemini Machine Learning Chrome Extension
